# PokemonImageRepository
Repository of Pokemon Images, which can be used for direct linking in various places. The following are available:
- Render - The main art that represents the design, unofficially referred to as the "Sugi Art" in many places
- Sprite - The BW-styled sprite, which is official up through Gen 5, and custom starting from Gen 6. These sprites are made by the Smogon Community.
- Icon - The small menu icons displayed in Gen 7. These images are official up through Gen 7, and starting with Gen 8, some Images may begin using custom images styled after Gen 7's dimensions.

## Naming Reference
Each image file is named using a certain schema based on the Pokemon's name and form, (if it has a form name). Normally, this is simply just an undercased spelling of the Pokemon's name. For complex names or names with special characters, this becomes convoluted, so a rule was created when naming these images:
1. The Pokemon's name will only contain alphanumeric characters, (only letters and numbers). Anything else is stripped away
2. If the Pokemon has a form name, append a "-" character. The form name is appended after, undercased and stripped of any non-alphanumeric characters, (similar to the name).

Some examples of this utilization:
- Bulbasaur -> bulbasaur
- Venusaur-Mega -> venusaur-mega
- Porygon2 -> porygon2
- Porygon-Z -> porygonz
- Type: Null -> typenull
- Maushold - Family of Three -> maushold-familyofthree
