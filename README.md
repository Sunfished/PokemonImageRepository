# PokemonImageRepository
Repository of Pokemon Images, which can be used for direct linking in various places. The following are available:
- Render - The main art that represents the design, unofficially referred to as the "Sugi Art" in many places
- Sprite - The BW-styled sprite, which is official up through Gen 5, and custom starting from Gen 6. These sprites are made by the Smogon Community.
- Icon - The small menu icons displayed in Gen 7. These images are official up through Gen 7, and starting with Gen 8, some Images may begin using custom images styled after Gen 7's dimensions.
